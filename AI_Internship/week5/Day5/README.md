## 🔑 Key Findings / Decisions

- **Selected project: Fraud Detection Model** — imbalanced binary classification, chosen over Customer Churn Prediction (the safer, more familiar alternative) because it builds on my existing classification/evaluation skills while adding two genuinely new, portfolio-worthy skills: imbalance handling (SMOTE) and model explainability (SHAP).
- **Sprint 1 goal:** understand the data and establish a baseline model to beat — the same baseline-first discipline used since Week 3.
- **Sprint 1 backlog:** three tasks (dataset selection, EDA, baseline model), each with its own effort estimate and written acceptance criteria, deliberately scoped to exclude imbalance-handling and SHAP until a baseline exists to compare against.
- **Repository decision:** the capstone lives in a new, separate GitHub repository (distinct from this `BinX_Internship` training repo), since it's a standalone, product-style deliverable with its own deployment, model artifacts, and technical write-up.
